# 💄 Glitz & Glam – Makeup Artist Portfolio Website

**Glitz & Glam** is a professional portfolio website built for a makeup artist to beautifully showcase bridal/event looks, client testimonials, and allow users to book appointments and reach out directly — all through a clean, responsive UI.

---

## 🌐 Live Demo

🔗 [Visit Website](https://glitz-and-glam.netlify.app/)

> The frontend is live on Netlify. Backend APIs are functional locally but not yet deployed.

---

## ✨ Features

- 🌟 Elegant landing page with hover-based service previews
- 💍 Services gallery: Bridal, Haldi, Mehndi, Reception, Sangeet, Party
- 💬 Client testimonials with names and reviews
- 📽️ “Our Journey” page with portfolio video and experience
- 📅 Booking form (connected to backend locally)
- 📞 Contact page for phone/email inquiries
- 📱 Responsive design for mobile and desktop

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- Vanilla CSS (custom design)
- Netlify (deployment)

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- formspree (for contact/booking form emails)
- [Currently not hosted — runs locally]
